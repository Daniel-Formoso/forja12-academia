# Forja 12 Academia

Landing page conceitual de uma academia inteiramente fictícia, criada como peça de portfólio.

**Site:** [forja12-academia.vercel.app](https://forja12-academia.vercel.app)

## Stack

- Next.js com App Router
- React e TypeScript
- Tailwind CSS v4
- Componentes shadcn/ui

## Desenvolvimento

```bash
npm run dev
```

Abra `http://localhost:3000`.

## Aviso

Marca, logo, fotografias, preços, horários, modalidades e localização são demonstrativos. O projeto não representa uma academia real.
